# Prototypes

Code **jetable**, conservé comme source primaire, jamais fusionné dans `main`.

Chaque sous-dossier pose une question de conception et contient la réponse sous forme
exécutable. Le verdict est consigné en commentaire de résolution sur le ticket
correspondant de la carte de wayfinding, et la décision validée est repliée dans le
vrai code.
