# Labels de triage

Les skills raisonnent en termes de cinq rôles canoniques de triage. Ce fichier mappe ces rôles vers les chaînes de labels réellement utilisées dans l'issue tracker de ce repo.

| Rôle dans mattpocock/skills | Label dans notre tracker | Signification                              |
| ---------------------------- | ----------------------- | ------------------------------------------ |
| `needs-triage`               | `needs-triage`          | Le mainteneur doit évaluer cette issue     |
| `needs-info`                 | `needs-info`            | En attente d'informations du rapporteur     |
| `ready-for-agent`            | `ready-for-agent`       | Entièrement spécifié, prêt pour un agent AFK |
| `ready-for-human`            | `ready-for-human`       | Nécessite une implémentation humaine        |
| `wontfix`                    | `wontfix`               | Ne sera pas traité                         |

Quand une skill mentionne un rôle (ex. « applique le label de triage prêt pour l'agent AFK »), utilise la chaîne de label correspondante dans ce tableau.

Édite la colonne de droite pour coller au vocabulaire que tu utilises réellement.
