## Merge Danger

**Door:** two-way

Documentation seulement — aucune ligne du cœur ne change de comportement. Le seul fichier source
touché est `registry/default/signals.ts`, et uniquement un commentaire : la citation
`site/utilisateurs/distribution.md` §5 pointait vers une section supprimée par la réécriture, et
`verifier-documentation` §11 l'aurait fait tomber. Elle pointe désormais vers ADR-0008, qui porte
la même contrainte. Un `git revert` restaure l'état d'avant sans autre conséquence.

**Blast Radius:** la section des adoptants du site

Les six fichiers de `site/contributeurs/` qui citaient `site/utilisateurs/parity.md` sont
repointés (SPEC, CONTRIBUTING, ROADMAP, documentation, index). Si l'un était oublié, le build
tombe sur un lien mort — la porte est verte, donc aucun ne l'est. Le README gagne un lien ; une
pull request ultérieure qui le retire ne casse rien d'autre.
